Repository evidence independently verified on 2026-11-07:
The index.html file contains eight Base64-encoded template chunks and a repeating-key XOR decoder. It was decoded statically inside an analysis VM; the HTML/JavaScript and advertised commands were not executed.

The decoded page instructs users to run PowerShell to download and immediately execute content from:
hxxps://activation-gateway[.]cc/update/ps-release

Decoded HTML line 507 contains the download-and-execute command; line 533 presents a second variant using ExecutionPolicy Bypass. Line 543 instructs users to pause real-time antivirus protection if the installer is blocked. Clipboard-copy functionality is provided for these commands.
